Populate Templates Tab

One-time script. Writes all current templates into the Templates tab of Solura_Lead_Tracker.xlsx.
Step 1. In Excel, create a new sheet tab named exactly Templates (case-sensitive, no spaces). Leave it empty — this script writes both the headers and the rows.
Step 2. Sign in with the same Microsoft account you use for the dashboard.
Step 3. Hit Populate. It writes ~110 rows, taking 30-90 seconds. Watch the log for progress.
Warning: If the Templates tab already has data, this script will overwrite it. Run only once.
